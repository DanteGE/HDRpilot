# HDRpilot 1.6.0

Deutsch weiter unten · German below

## English

HDRpilot turns Windows HDR on when a game starts and restores it afterwards, per game, with a game library to choose
which games get "HDR on launch". It runs for your Windows user only, without admin rights and without a service.

### New in 1.6.0

- **English user interface.** The whole app, the setup and the command line are available in English. New
  installations follow the Windows display language (German → German, any other language → English); existing
  installations keep German. Switch any time in Settings › General › "Language · Sprache" and restart.
- **Search SteamGridDB in "Choose image…".** With your own SteamGridDB API key you can search hero images, logos and
  covers for a game right in the dialog: about 24 previews per page with "Load more", only still images without NSFW or
  humor tags, the full image is downloaded only when you apply and is stored like a custom image ("Reset" keeps
  working). Nothing goes online before you click. The key now enables the search on its own; the switch only controls
  loading missing images automatically.
- **Colors follow the game** (optional, off by default). The library's accents take on the colors of the selected
  game's logo and cover, read once per game; gray art keeps your color scheme. With the switch off it costs nothing.
- **Library feedback from the 1.5.0 test:**
  - The hero image's parallax glides back smoothly when the pointer leaves the image.
  - The hero height can be dragged in List, Grid and Shelf; each view remembers its own height.
  - Tile glow is no longer cut off, and hovered tiles in the top row grow downwards instead of hiding under the toolbar.
  - The "Hide toolbar" tab sits exactly centered on the image edge.
  - The pill between the list and the details is now the real scroll bar of the list and grid.
  - Windows Auto HDR explanations in the details are collapsed behind "Learn more".
  - Filter buttons look selected only while the filter is on; the focus ring appears only for keyboard use.
  - The big title shows the selected source ("Steam games", …) with its counts; click it to switch the source.
  - Ctrl+F now shows and hides the toolbar (Ctrl+Shift+F is gone).
  - Menu buttons ("···", the icon tile, the title) close their menu on a second click.
- The setup installs both READMEs (English `README.md`, German `README.de.md`).

### Install

Download `HDRpilot-Setup-1.6.0.exe` and run it. It installs for your Windows user and updates an existing
installation in place; your settings stay as they are. The file is not signed, so Windows SmartScreen may ask once.

## Deutsch

HDRpilot schaltet Windows-HDR beim Start eines Spiels ein und danach wieder zurück, je Spiel einstellbar in einer
Spielebibliothek („HDR automatisch“). Es läuft nur für deinen Windows-Benutzer, ohne Adminrechte und ohne Dienst.

### Neu in 1.6.0

- **Englische Oberfläche.** Die ganze App, das Setup und die Kommandozeile gibt es auch auf Englisch. Neue
  Installationen folgen der Anzeigesprache von Windows (Deutsch → Deutsch, jede andere Sprache → Englisch); bestehende
  Installationen bleiben auf Deutsch. Umstellen jederzeit unter Einstellungen › Allgemein › „Sprache · Language“, danach
  neu starten.
- **SteamGridDB-Suche in „Bild wählen…“.** Mit eigenem SteamGridDB-API-Schlüssel suchst du Titelbilder, Logos und Cover
  direkt im Dialog: etwa 24 Vorschauen je Seite mit „Mehr laden“, nur unbewegte Bilder ohne NSFW- und Humor-Markierung;
  das volle Bild lädt HDRpilot erst beim Übernehmen und speichert es wie ein eigenes Bild („Zurücksetzen“ geht weiter).
  Vor deinem Klick geht nichts ins Netz. Der Schlüssel schaltet die Suche frei; der Schalter regelt nur noch das
  automatische Laden fehlender Bilder.
- **Farben folgen dem Spiel** (wählbar, Standard aus). Die Akzente der Bibliothek übernehmen die Farben von Logo und Cover
  des gewählten Spiels, einmal je Spiel ausgelesen; bei grauen Bildern gilt dein Farbschema. Ausgeschaltet kostet es nichts.
- **Rückmeldungen aus dem Test von 1.5.0:**
  - Die Tiefenwirkung des Titelbilds gleitet weich zurück, wenn der Zeiger das Bild verlässt.
  - Die Höhe des Titelbereichs lässt sich in Liste, Raster und Regal ziehen; jede Ansicht merkt sich ihre eigene Höhe.
  - Das Leuchten der Kacheln wird nicht mehr abgeschnitten, überfahrene Kacheln der ersten Reihe wachsen nach unten statt
    unter die Werkzeugleiste.
  - Die Lasche „Leiste ausblenden“ sitzt genau mittig auf der Bildkante.
  - Die Pille zwischen Liste und Details ist jetzt die echte Bildlaufleiste von Liste und Raster.
  - Die Erklärungen zu Windows Auto HDR in den Details stehen zugeklappt hinter „Mehr erfahren“.
  - Filterknöpfe sehen nur gewählt aus, solange der Filter an ist; den Fokusrahmen gibt es nur bei Tastaturbedienung.
  - Der große Titel zeigt die gewählte Quelle („Steam-Spiele“ …) mit ihren Zahlen; ein Klick darauf wechselt die Quelle.
  - Strg+F blendet die Werkzeugleiste ein und aus (Strg+Umschalt+F entfällt).
  - Menüknöpfe („···“, die Symbol-Kachel, der Titel) schließen ihr Menü beim zweiten Klick.
- Das Setup installiert beide READMEs (englisch `README.md`, deutsch `README.de.md`).

### Installation

`HDRpilot-Setup-1.6.0.exe` herunterladen und starten. Es installiert für deinen Windows-Benutzer und aktualisiert eine
vorhandene Installation; deine Einstellungen bleiben, wie sie sind. Die Datei ist nicht signiert, deshalb fragt Windows
SmartScreen beim ersten Start eventuell nach.
